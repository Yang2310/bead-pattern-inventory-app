# 产品功能说明

[English](features.md) | **简体中文**

## 1. 首页与导航
提供制作图纸、导入已有图纸、图纸库和拼豆库存等功能入口。**体现：** 多页面微信小程序交互。

## 2. 制作可编辑拼豆图纸
将普通图片转换成拼豆网格数据，支持颜色匹配、预览、单格编辑和保存。生成结果是结构化图纸，而不仅是一张导出图片。**体现：** 图片处理、API 协作和数据建模。

## 3. 导入已有图纸
上传已有拼豆图纸，对图片裁剪并进行必要的网格检查、人工校准，保存参考图片以继续拼图。**注意：** 这里不宣称能自动识别每一个豆号。**体现：** 与制作图纸不同的导入流程及人工纠错能力。

## 4. 图纸库与进度管理
浏览制作或导入的图纸、重新打开、管理状态、标记完成区域并持久化进度。**体现：** 多步骤业务流程与状态保存。

## 5. 按系列和颜色管理库存
按色板系列及单色查询、调整拼豆库存数量。**体现：** 关系型数据与库存业务操作。

## 6. 库存结算与流水
记录直接库存调整及图纸生命周期相关的库存变化；重复同步与重新开始等流程需要防止重复扣减。**体现：** 后端业务规则和可追溯的流水记录。

## 7. 图片和结构化数据分离存储
结构化图纸与库存数据存入 MySQL，需要长期保存的参考图像交由腾讯 COS。**体现：** 数据库与对象存储的职责分离。

## 8. 内容安全和用户服务
相关的用户名称、图片输入接入微信内容安全检查，并提供反馈、隐私说明和用户数据清理等流程。**体现：** 外部 API 集成。

## 9. 部署与性能排查
提供 Docker Compose/Nginx 部署支持、健康/就绪检查；针对图纸列表查询大 JSON 的内存问题采用延迟加载。**体现：** 部署工程和真实数据库问题排查。
