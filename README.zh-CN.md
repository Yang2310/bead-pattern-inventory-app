# 拼豆图纸与库存管理小程序

一个用于创建、管理和记录拼豆图纸及拼豆库存的全栈微信小程序。

> **角色：** 独立全栈开发  
> **技术重点：** FastAPI 后端 · REST API · 图片转图纸 · 库存管理 · 云存储 · 自建部署

[English](README.md) | **简体中文**

## 项目概览

这个项目是一个完整的实际应用，而不是单独的技术 Demo。系统由微信小程序前端和 FastAPI 后端组成，覆盖从图片生成拼豆图纸、已有图纸管理，到库存记录和使用进度管理的一整套流程。

用户可以将普通图片转换成结构化拼豆图纸，也可以上传已有图纸；同时可以管理不同系列和颜色的拼豆库存、记录库存变化、保存图纸进度，并通过云对象存储保存长期图片资源。

完整实现保存在私有源码仓库中。本公开仓库仅用于作品展示，重点介绍产品能力、系统结构和工程实现，不公开生产源码、密钥或用户数据。

## 主要功能

### 图片转图纸

用户上传普通图片后，可以将其转换为可继续编辑和预览的结构化拼豆图纸。生成结果不仅是一张静态图片，还会保存颜色、数量、编辑状态和进度等应用数据。

### 图纸管理

系统同时支持生成图纸和上传已有图纸。用户可以管理已保存图纸、查看预览、记录进度、重新开始或删除图纸，并由后端业务规则同步处理相关状态。

### 库存管理

库存既可以按拼豆系列管理，也可以精确到单个颜色。库存变化通过流水逻辑记录，使图纸完成、重置和删除等操作能够一致地扣减或恢复库存。

### 后端与存储

FastAPI 负责 API、数据校验、持久化和主要业务流程。长期图片资源存储在腾讯云 COS，结构化图纸和库存数据存储在数据库中。

### 内容安全与用户数据

用户提交的文本和图片可以通过微信内容安全 API 检查。应用也包含反馈、隐私说明和用户数据清理相关流程。
