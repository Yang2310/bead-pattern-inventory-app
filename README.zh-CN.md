# 拼豆图纸与库存管理小程序

**微信小程序全栈应用 | Python · FastAPI · MySQL · 图片处理 · 腾讯云 COS**

将普通图片转为可编辑拼豆图纸，并把图纸制作进度、库存数量与库存流水关联起来的完整应用。

**源码范围：** 完整实现保存在私有仓库；此仓库是供招聘方查看的公开作品展示，不包含敏感数据。

## 核心功能

1. **普通图片制作图纸：** 生成结构化拼豆网格，预览、修改豆号和颜色，并保存图纸与进度。
2. **导入已有图纸：** 上传拼豆图纸图片，对图纸进行裁剪和必要的网格人工校准，放入同一图纸库管理。该流程**不能宣传成全自动识别每一种豆色**。
3. **图纸制作与进度：** 打开已保存的图纸，查看用量，标记已完成区域并保留进度。
4. **拼豆库存管理：** 按色板系列和单色管理库存，增减数量并查看变动流水。
5. **图纸与库存联动：** 按后端业务规则，在进度同步、完成、重新开始或删除时结算和返还库存，记录相关流水。

功能详情：[功能说明](docs/features.zh-CN.md)。

## 关键工程实践

- **前后端分离：** 微信小程序通过 REST API 调用 Python/FastAPI 后端，数据校验、库存规则和持久化主要在服务端完成。
- **结构化图片处理：** 制作图纸保存可编辑的网格、豆色及进度数据，而不是只保存一张平面图片；导入的现有图纸可保留裁剪后的参考图片。
- **库存一致性：** 图纸生命周期和库存流水关联，需要避免重复同步已完成区域时重复扣减库存。
- **实际数据库问题排查：** 针对图纸列表读取大体积结构化 JSON 导致的 MySQL 排序内存错误，使用延迟加载调整查询路径。
- **服务集成与部署：** MySQL、腾讯 COS、微信内容安全接口、Docker/Nginx 自建部署，以及后端健康/就绪检查。

上述内容基于项目实现和已有测试、联调记录，不代表所有边界都已通过独立验收，也不代表现在有持续运行的公开服务器。
